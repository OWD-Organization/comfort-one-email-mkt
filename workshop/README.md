# OWD workflow foundation — team workshop

This folder is a **discussion deck**, not a decision.

Open `index.html` in a browser (Chrome or Edge). Use **arrow keys** or the on-screen buttons. Press **P** to print / save as PDF.

## How to run the session

1. Technical and non-technical people in the same room (or Slack huddle).
2. Goal of this meeting: **share a map**, not pick a winner.
3. Capture questions on the last slides. Schedule a second meeting to decide.

Do not enable new automations or create client repos as an outcome of the first pass unless everyone agrees the item is obviously safe (for example: “never mix client logins”).
